# 🥗 Cotizador Balance Lunch

Mini web app interna diseñada para calcular rápidamente cotizaciones de pedidos y generar resúmenes formateados para enviar por WhatsApp.

## 🚀 Características
- **Selección de productos:** Almuerzo Completo, Acompañamientos y Packs promocionales.
- **Canales de entrega:** Recojo en punto de venta y Delivery en Heredia (₡2,500).
- **Copiado rápido:** Botón para copiar el resumen directamente al portapapeles en formato listo para WhatsApp.
- **Diseño Mobile-First:** Diseñado para uso rápido desde smartphones.

## 🛠️ Tecnologías
- HTML5
- CSS3 (Flexbox, CSS Variables, CSS Grid)
- JavaScript Vanilla (DOM manipulation, Clipboard API)
